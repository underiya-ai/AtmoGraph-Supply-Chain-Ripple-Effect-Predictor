
# AtmoGraph - Supply Chain Ripple Effect Prediction

## Project Overview
AtmoGraph is a supply chain disruption prediction project.
It aims to understand how disruptions in one part of a supply chain
can affect other connected entities.

## My Role
Graph Network Development

## Responsibilities
- Develop supply chain graphs.
- Connect suppliers, factories, warehouses and retailers.
- Develop ripple effect simulation.
- Identify potentially affected entities.
- Analyse supply chain network connections.
- Visualize the supply chain network.
